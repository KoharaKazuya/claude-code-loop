## 確認事項

一言でいうと: **`ccloop status` に「自律ループが今も動いているかどうか」を出してよいか。**

### なぜ聞いているか

改善のネタごとに確認を取る運用にしているため、その 1 件として提案している。表示が増えるので
確認したい。

### いまどうなっているか

`ccloop status` の「稼働状態」に出るのは、これまでに動かしたセッションの数と、最後に探索を
行った時刻だけである(`lib/supervisor.ts:4452`)。**ループ本体(`ccloop run`)が今も生きているか
どうかは、どこにも出ていない**。

そのため、実行中のタスクが 0 件で「実行中のタスク: なし」と表示されているとき、それが

- たまたま手が空いているだけなのか
- ループ本体が落ちていて、もう誰も何も進めていないのか

を、表示から区別できない。後者に気づかないまま「動いているはず」と思って放置する事故が起こりうる。

### やるとしたら何をするか

ループ本体の実行中を示す情報を記録しておき、`status` を打ったときに生きているかを確かめて
「動いています / 動いていません」を 1 行出す。あわせて、状態が最後に更新された時刻も出す
(いつの情報を見ているかが分かるようにするため)。

小さく済ませるなら「最後に状態が更新された時刻を出すだけ」でも、古さには気づけるようになる。

### やらない場合どうなるか

いまのまま。ループが止まっていることに気づく手段は、`ccloop status` の表示がいつまでも
進まないのを見て察するか、プロセスを自分で確認するかになる。
