## 何が起きているか

セッション終了後の後始末(`lib/supervisor.ts` の `finishTaskSession`)は、次の順で進む。

1. 実行中の記録を「後始末中」に書き換える(`lib/supervisor.ts:3211-3214`)
2. main へマージする
3. **マージ成功なら作業場所とブランチを削除する**(`lib/supervisor.ts:3263-3273`)
4. 結果を分類する(`lib/supervisor.ts:3330-3377`)。ここで初めて「セッションが `status` を
   更新しなかった」ケースを拾い、`no-status-update` として失敗計上・`note` 記録を行う
5. `finally` で実行中の記録を消す(`lib/supervisor.ts:3392-3396`)

**3 と 4 の間でプロセスが強制終了される**(`kill -9` / OOM / ホスト再起動など、`try/catch` で
捕まらない中断)と、痕跡が何も残らない。

- 作業場所もブランチも既に消えているので、起動時の孤児ブランチ回収は `refs/heads/agent/*` を
  起点にしており対象に上がらない(`lib/supervisor.ts:1388-1418`)
- 実行中の記録は起動時に中身を検査せず無条件に空にされる(`lib/supervisor.ts:1434-1448`)
- 旧 `status: working` を拾う回収経路も、現行の Supervisor は実行中に `status` を書き換えないため
  掛からない(`lib/supervisor.ts:1420-1432`)

結果、タスクファイルは起動前のまま(通常 `ready`)残り、`retries` も増えず、`note` にも
`## 試行履歴` にも一切記録が残らない。

## 実害

- **変更は main に入っているのに、`ccloop status` にはそのタスクが「次に実行予定」としか出ない。**
  何かが起きた形跡が一切見えない。
- 次の周回で同じタスクが未着手として再選定され、既に main へ反映済みの変更の上に別セッションが
  起動する。エージェントはタスク本文から前回の作業を知りようがなく、二重実装や自己矛盾する
  変更につながりうる。
- 本来 `no-status-update` が捕まえるはずだった「セッションが `status` 更新を怠った」という
  兆候も失われる。退行の検知手段が 1 つ消える。

## 隣接するケース(こちらは自己修復されるので直す必要はない)

作業場所の削除とブランチの削除の**間**で死んだ場合は安全である。ブランチが残るので次回起動の
孤児ブランチ回収が拾い、`mergeAgentBranch`(`lib/merge.ts:385-407`)が差分 0 を
`nothing-to-merge` と判定するため二重マージにならない。危険なのは
**「作業場所もブランチも消え、かつタスクファイルの `status` が未更新」**という組み合わせだけである。

## やること

1. 上の分析をコードで裏取りする(調査はコード読解のみで、実機再現はしていない)。
2. 3 と 4 の間に痕跡が残らない区間をなくす。方向性はいくつかありうる:
   - 削除の前に分類・タスクファイルの更新を済ませる(順序を入れ替える)
   - 実行中の記録に「マージ済みだが分類前」を残し、起動時にそれを見て分類をやり直す
     (今は中身を検査せず捨てている)
   どちらを選ぶかは実装時に判断し、理由を `.agent/decisions/` に記録する。
   **順序の入れ替えは、失敗経路で作業場所を残す既存の扱いと衝突しうる**ので、そこを崩さないこと。
3. この中断点を再現するテストを足す(実際にプロセスを殺す必要はなく、後始末を途中で打ち切った
   状態を作って起動時復旧を走らせれば足りる)。
4. 利用者から見た挙動が変わるので `CHANGELOG.md` の「## 未リリース」に 1 行足す。

## 完了条件

後始末の途中で中断されても、タスクが「未着手」のまま痕跡なく戻る経路が無くなること。
機械的検証が通ること。

## 補足(次に掘る人向け)

この件と併せて調べた範囲では問題は見つからなかった。`lib/watch.ts` は `formatStatus()` を
呼ぶだけの薄いループで独自の状態分類を持たない。`lib/liveness.ts` の判定は網羅的。
`recoverOrphanBranch` の各分岐も取りこぼしなく分類されている。同じ場所を再度掘らないこと。
