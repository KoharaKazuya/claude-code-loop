# GOAL(人間が方向性を与える場所)

このファイルが自律実行の**最上流の入力**である。人間が自由に編集してよい(むしろ人間しか書けない)。
内容は全セッションのプロンプトに注入され、探索セッションはここから新しいタスクを導出する。
変更は次のセッションから反映される。

---

## ミッション(このリポジトリは何のためにあるか)

ccloop(Claude Code ベースの自律開発ループ CLI)自身を開発・改善する。
人間が GOAL を与えるだけで、探索→タスク分解→実装→検証→人間レビューのループが
安全に回り続ける状態を維持し、ドッグフーディングで見つかった摩擦を解消し続ける。

## 現在の目標(いま何を達成したいか)

- `.agent/tasks/` の ready タスクを消化する(decisions アーカイブの人間承認化、
  `ccloop status` への未承認決定の表示)
- 人間の確認・介入の導線(human-review、decisions、status 表示)を磨き、
  ループの外から状況を把握しやすくする

## 制約・前提

- ツール本体は DevContainer feature として配布し、利用側リポジトリに残すのは `.agent/` のみ
- permissions の deny リストと PROMPT.md の絶対ルールは常に一致させる(二重の担保)
