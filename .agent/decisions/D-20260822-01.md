reversibility: high
createdAt: 2026-08-22T08:46:31.964Z

`.devcontainer/post-create.sh` の末尾にあった、このリポジトリの checkout(`bin/ccloop`)を
`/usr/local/bin/ccloop` に symlink するセクションを削除し、代わりに `.devcontainer/devcontainer.json` /
`devcontainer-lock.json` に公開済み feature `ghcr.io/koharakazuya/claude-code-loop/ccloop:0.1.0` を
バージョン固定で追加した。

理由:

- 利用者と同じインストール経路(feature 経由)で動かすことで、install.sh や feature 定義自体の不具合を
  この開発コンテナで検出できる。
- 自律ループがこのリポジトリの `lib/` を書き換えても、コンテナ内で動いている `ccloop` は feature 側の
  固定コピーなので影響を受けない(実行中のツールが自己改変で壊れない)。

ローカルの `lib/` 変更を試すときは `./bin/ccloop <subcommand>` を直接実行する(symlink には依存しない)。

副次的な修正として、README.md の「インストール」節にあった存在しないタグ `:1` を、現行 0.x のメジャー
タグ `:0` に修正した。

検討した代替案:

- 従来どおり symlink を維持する: feature 自体の動作確認ができず、自己改変の影響も受けるため却下。

影響範囲・申し送り: `.claude/worktrees/readme-version-sync` に README のバージョン同期に関する未完作業が
あり、マージ時に競合する可能性がある。その作業では `devcontainer.json` の feature バージョンも同期対象に
含めるのが望ましい。

未確認事項: `devcontainer-lock.json` の追加エントリは `devcontainer features` の実際の解決結果ではなく
手書き(タスク指示で与えられた値をそのまま転記)のため、次回コンテナリビルド時に CLI が再生成した内容と
差分が出ないか要確認。
