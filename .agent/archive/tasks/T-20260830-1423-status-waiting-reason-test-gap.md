事前の確認(Human Review)は不要な範囲。

## 目的

`ccloop status` の「次に実行予定のタスク」が空のときに出す待ち理由の表示に、成立しうる 3 通りの
うち 1 通りしかテストが無い。残りを埋めて、今後この分岐を触ったときに退行を機械的に検知できる
ようにする。

## 現状(確認済みの事実)

`lib/supervisor.ts:6339-6345` は待ち理由を配列に積んで連結する実装で、出力は次の 3 通りになりうる。

- `なし(競合待ち N 件)`
- `なし(スヌーズ待ち N 件、最短解除 <日時>)`
- `なし(競合待ち N 件、スヌーズ待ち N 件、最短解除 <日時>)`

このうちテストがあるのは 1 つ目だけ(`lib/supervisor.status.test.ts:593-611`)。これは修正前の
実装(片方だけを出す三項演算子)でも同じ出力になるケースであり、今回の修正で初めて可能になった
2 つ目・3 つ目を通るテストは存在しない(`grep -rn "スヌーズ待ち\|最短解除" lib/*.test.ts` が
無ヒットであることを確認済み)。

## 完了条件

- `lib/supervisor.status.test.ts` に、上記 2 つ目・3 つ目の出力を検証するケースを追加する。
- `npm test` / `npm run lint` / `npm run typecheck` が通る。
- 実装(`lib/supervisor.ts`)は変更しない。テストを足した結果として実装の誤りが見つかった場合のみ、
  理由を `.agent/decisions/` に記録したうえで直す。
