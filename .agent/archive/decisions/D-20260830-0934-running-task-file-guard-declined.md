## 判断

実行中タスクの `.agent/tasks/<id>.md` を他のセッションが書き換えられないよう、
コード側で書き込みを拒否する(または事後に検出して知らせる)対応は**やらない**。
今後この案を再提案しない。

## 理由

`HR-20260830-0825-topic-running-task-file-guard` で人間が「やらない」と回答した。

提案時に挙げた論点のとおり、守りを固くするほど正当な修正(明らかに壊れた記録を直す等)まで
止めてしまう。実害が出た記録はまだ無く、同じ行を書き換えた場合はマージが衝突として止める。

## 影響範囲

実行中タスクの記録を守るのは、これまでどおり**プロンプトの指示だけ**である
(探索セッションのプロンプトに実行中タスクの一覧を注入し「編集しないこと」と書く方式)。
別々の行を書き換えた場合に両方の変更が静かに混ざる可能性は残る。受容する。
